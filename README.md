# kontavie ML – Updates

Dieses öffentliche Repository enthält nur die Versionsdatei `latest.json` für die Funktion **„Auf Update prüfen“** in kontavie ML (Einstellungen → Updates).

- **Kein Quellcode, keine Daten.** `latest.json` nennt Version, Datum, Datenformat, Stichpunkte zur Version sowie Download-Adresse, Dateiname, Größe und SHA-256-Prüfsumme des Pakets.
- Die App lädt die Datei nur, wenn du auf „Auf Update prüfen“ klickst – ohne Cookies, ohne Referrer und ohne Daten aus deinem Tresor.
- Die App installiert nichts selbst. Du lädst das Paket im Browser, vergleichst die Prüfsumme und startest den Installer.

Solange hier keine `latest.json` liegt, meldet die App „Es ist noch keine Version veröffentlicht.“
